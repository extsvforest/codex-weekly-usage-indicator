# Privacy

Codex Weekly Usage Indicator reads one value from the locally installed Codex app-server: the current rate-limit windows used to calculate the remaining weekly percentage.

The application:

- does not store usage history;
- does not read or store authentication tokens;
- does not collect account identifiers;
- does not include telemetry;
- does not make its own outbound network requests.

Codex Desktop and its local app-server remain governed by their own terms and privacy practices.

When reporting a bug, do not attach Codex logs, configuration files, tokens, or screenshots containing information you do not want to publish.
